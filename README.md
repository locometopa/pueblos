# Mis pueblos

Datos y generador de mi web de pueblos visitados.

- `datos/` — un pueblo por carpeta (`pueblo.json`, `fotos/`, `mini/`). Las fotos ya están reducidas y sin GPS.
- `generador/` — código que crea la web (lo ejecuta GitHub Actions en cada cambio).
- Panel de gestión: `/gestion/` dentro de la web.

Se edita con el programa PUEBLOS (Windows) o desde el panel web. No hace falta tocar nada aquí a mano.
